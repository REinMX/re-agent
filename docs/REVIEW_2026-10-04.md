## Verdict

A useful personal engineering toolkit with substantially better regression coverage than a prompt-only
"reservoir agent". It is not an autonomous reservoir engineer, an enterprise security boundary, or a
verified company deployment. The right next step is a small public-data pilot through your approved
Windows VS Code agent, with explicit manual execution in Komodo. Do not build a second agent framework.

The existing design is worth retaining: one skill source, small deterministic scripts, familiar
open-source FMU readers, CSV outputs, explicit numerical-percentile semantics, and separate analyst/operator
roles. The material-balance reference fixtures and public Reek integration tests are real strengths.

## Important findings at baseline `5bd0dda`

Line references below describe the original baseline, not the changed line numbers.

1. **P1 — Plausible statistics could hide missing data.**
   `skills/res2df-resdata-extract/scripts/ensemble_summary.py:172-205` accepted a nonempty frame even
   when one requested key was missing, intersected away unequal member columns, and coerced invalid
   cells to NaN before pandas silently reduced the statistic count. Units came from one member only
   (`:86-98,217`). New adversarial tests reproduced successful exits with missing keys, unequal calendars,
   NaN/Inf and inconsistent units. Fixed: validate requested patterns, aligned output dates/source periods,
   equal vector sets/units, finite cells and finite/full-count derived statistics before output.

2. **P1 — An incomplete observation comparison could look successful.**
   `skills/history-match-qc/scripts/misfit_report.py:226-230,461-470,522` dropped absent residuals and
   failed only if none remained. A test reproduced exit 0 and misfit 0 using one of two observations.
   Fixed: incomplete/nonfinite prediction coverage fails; partial evidence still returns failure; raw
   member data and prior/posterior member identities are checked. This remains a diagnostic, not ERT's
   objective or a scientific history-match acceptance gate.

3. **P1 — Material-balance validation was not numerically fail-closed.**
   `skills/material-balance/scripts/mbal.py:68-82,246-248,525-545` accepted infinity and optional NaN,
   did not validate most numeric options, and serialized nonstandard NaN/Infinity JSON with success.
   A `--cw nan` regression reproduced that behavior. `:142-147` accepted unordered dates for aquifer
   integration. Fixed: finite/nonnegative options and columns, strictly ordered dates, checked final
   numeric serialization, and controlled failure on overflow before any output directory is created.
   Existing oil/gas/aquifer reference tolerances remain unchanged.

4. **P1 — Safety claims exceeded the controls.**
   `README.md:7-8` claimed harness enforcement; `tools/gate_hook.py:12,61-85,133-135` failed open on
   malformed JSON and did not gate direct simulators, SSH or inline Python. `.codex/rules/gates.rules`
   was a prefix policy, not an equivalent universal hook. Official Codex docs explicitly scope rules
   to outside-sandbox execution. Fixed recognized-command classification/malformed input and corrected
   the claims. Remaining: arbitrary code/file/MCP operations, absolute-path prefixes, hook availability,
   configuration trust and endpoint policy require the approved harness/OS/site controls.

5. **P1 — Windows-only access was not a supported topology.**
   The setup guide of that time (now `docs/SITE_SETUP.md`) assumed a remote agent installation.
   `tools/install_user_skills.sh:16-34` required Linux symlinks and global setup. Fixed via Windows-first
   manual-handoff guidance and a project-scoped copy installer. Automatic SSH is deliberately not added;
   an unrestricted remote-shell wrapper would increase risk rather than establish compatibility.

6. **P2 — Eval results could be false green.**
   `evals/runner.py:439-441` ignored the harness exit/completion status; `:407` truthified strings such
   as `"false"`; `:533` allowed all selected cases to skip with success. Fixed terminal/exit gates,
   strict judge booleans/evidence, default failure on skipped coverage and harness-specific model defaults.
   The deterministic runner tests use synthetic protocol records, not invented real model responses.

7. **P2 — Reusing report directories could mix old and new evidence.**
   `skills/case-qc/scripts/case_qc.py:133,285-310` read pre-existing manifests from an output directory,
   including steps not run in the current request. Fixed by requiring a fresh directory and rejecting
   overlap with supplied runpath/directory input trees before any child tool launches.

8. **P2 — Readiness evidence was too environment-dependent.**
   Default `make check` failed here due to missing Ruff in the system interpreter; the lean venv passed
   116 tests with 8 skipped tests/modules. The existing FMU lab environment passed all 222 baseline
   tests. Added a non-executing doctor and Windows/Linux CI configuration. Do not call skipped module
   counts the number of uncovered test functions. Actual Windows CI and corporate Komodo remain unrun.

## Limits and next decisions

- The site contract is an attestation and workflow configuration, **not enforced DLP or a universal
  output-root restriction**. Standalone scripts can be invoked with other output directories.
- Matching member periods cannot prove an intended forecast horizon if every member is equally truncated.
  Source-period alignment is not proof of successful simulator completion; use run/PRT/triage evidence too.
- Resampling still uses res2df semantics. Avoid interpolated rates for volume accounting; use cumulatives.
  No change to tank-model assumptions makes material balance valid for every heterogeneous field.
- Native Windows execution, actual VS Code permission/skill discovery, internal Komodo versions/plugins,
  LSF/licenses, Sumo and corporate endpoint policy have not been exercised here.
- No LICENSE file exists. Decide allowed redistribution/rehosting with the owner/site; do not invent a license.
- The old global symlink installer is retained for compatibility, not recommended as the workplace default.
- Protected `AGENTS.md` edits timed out awaiting approval. The file is unchanged; its original startup/link
  wording needs the approved follow-up update. Use the new guide/router for the deployment boundary.
- Independent review was attempted; both delegated reviewers failed on provider HTTP 402 (insufficient balance).
  Their completed transcripts were checked; no independent scientific/security approval was obtained.
