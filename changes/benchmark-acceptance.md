### Fixed
- `tools/drogon_lite_bench.py` fails closed. `grade()` creates `--out` itself and refuses an existing folder or one that overlaps the case, so an old `misfit/manifest.json` is never read. `misfit_report.py` runs without `--allow-partial` and with `--expected` from `NUM_REALIZATIONS` of the case config; a nonzero exit is an error, and its command, exit code, stdout and stderr are kept in `<out>/misfit_report.log`.
- The bench grades only the configured domain. The misfit manifest must list exactly the configured members for prior and posterior, with no missing member and no issue. Coverage gets `expected_members` and `expected_obs` (the SUMMARY_OBSERVATION names of the case observation file). The truth file must give a value for every configured observation, and GEN_KW distribution errors are refused. These checks run before `misfit_report.py`. Observation files with other observation kinds are refused, because the bench does not pass the GEN_DATA sources that `misfit_report.py` needs for them.
- Before the subprocess runs, truth must cover every bounded GEN_KW parameter. Exact names and bare aliases use the compensation check's matching rules. Ambiguous, duplicate, and non-finite matches refuse. The only missing-truth exemption is `KVKH`, and it requires finite truth values for both `KVKH_UPPER` and `KVKH_LOWER`. Empty, absent, renamed, nested, or otherwise incomplete bounded truth refuses. Standalone compensation diagnostics still accept partial truth.
- The base `KVKH` exemption preserves the negative control. `KVKH` still counts for the compensation verdict and score and appears in `bench.json` `truth_missing`. `edge_flags_are_real` grades truth-covered EDGE parameters and reports the ungraded EDGE count. It fails when EDGE parameters exist but none has truth. With truth-covered EDGE parameters, the existing majority rule is unchanged.
- The bench uses the current `compensation_check` API. It reads prior and posterior with `read_ensemble(glob, None)`, passes configured members to `check_run` and `fit_from_manifest`, and checks the misfit manifest first. A single-run benchmark declares no seed. `judge()` adds an optional `unknown_edges` count. The score formula and other grading rules are unchanged. `bench.json` adds `members`, `observations`, `misfit_log`, and `truth_missing`.
