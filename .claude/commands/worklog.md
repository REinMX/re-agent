Write one work log entry for the task of this session.

1. Use the format in `skills/task-to-skill/references/worklog-template.md`.
2. Write the file `worklog/<today>-<short-name>.md` in the agent repository. Make the folder if it does not exist.
3. For `pattern`, use a short name for the kind of task. Read the other entries in `worklog/`.
   If one has the same kind of task, use its pattern exactly.
4. Mark each step "same" or "judgment".
5. Estimate `minutes` from the session. Write the skill that you used, or "none".
6. Write the kind of each input file. Do not write well names or scratch paths in the Inputs section.
7. Show the entry to the user in one short message.
