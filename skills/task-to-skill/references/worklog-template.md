# Work log entry

Use one file per task under the approved local `worklog/` root. Git must not track it.
The endpoint must permit its data. Gitignore does not protect model context.
Record measured values only. Use `unknown` when a time or cost meter is absent.

```markdown
# Task <local-id>
Date: <host timestamp>
Pattern: <stable workflow name>
Skill and source revision: <skill, tool versions, and uncommitted changes>
Task: <one sentence>
Inputs: <types and approved local references, not copied confidential content>
Steps: <common steps and judgment steps>
Output: <local artifacts>
Checks: <each required check and observed result>
Problems: <errors, missing evidence, and corrections>
Minutes: <measured or unknown>
Cost: <measured or unknown>
Review: <independent decision or pending>
Lesson: <local lesson reference or none>
Next step: <exact proposal or none>
```

Use the lesson template in `continuous-learning` for a reusable rule.
Use the run receipt in `earned-autonomy` for trials and authority review.
Do not make a lesson for every task. Store no transcript or secrets.
